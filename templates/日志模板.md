## 今天要做什么

开工前先写三行以内。如果写不出来，说明今天该先想清楚再动手。

## 实际做了什么

按时间顺序记，别美化。贴关键代码：

```cpp
void setup() {
  Serial.begin(115200);
  pinMode(LED_BUILTIN, OUTPUT);
}
```

贴图放在 `static/images/` 下，文件名带日期，正文里这样引用：

```markdown
![接线图](/images/2026-11-19-led.png)
```

## 遇到的问题 & 怎么解决的

**这一段是整篇最有价值的部分，不要跳过。**

格式建议：现象 → 我猜的原因 → 试了什么 → 真正的原因 → 解法。

> 现象：串口一直刷乱码
> 原因：波特率设成了 9600，但代码里是 115200
