## 今天要做什么

实现板载LED灯呼吸效果、蜂鸣器随着LED灯发声、通过按钮控制蜂鸣器发出响动

## 实际做了什么

###1.板载LED灯的呼吸效果:
把一步 10 ms 均分成 10 个 1 ms 小周期，每个周期内按亮度比例输出高电平。

```cpp
unsigned int periodUs = STEP_TIME_MS * 1000UL / PWM_CYCLES;      // 1000 us
unsigned int onUs = (unsigned long)level * periodUs / PWM_MAX;   // 按亮度比例

for (int i = 0; i < PWM_CYCLES; i++) {
  digitalWrite(LED_PIN, HIGH);
  delayMicroseconds(onUs);
  digitalWrite(LED_PIN, LOW);
  delayMicroseconds(periodUs - onUs);
}
```
###2.蜂鸣器发声
`tone()` 只需要在「开始响」时调用一次，重复调用会造成声音抖动，因此用状态变量记录：

```cpp
if (shouldSound && !buzzerSounding) {
  tone(BUZZER_PIN, BUZZER_FREQ_HZ);
  buzzerSounding = true;
} else if (!shouldSound && buzzerSounding) {
  noTone(BUZZER_PIN);
  buzzerSounding = false;
}
```
###3.通过按钮控制蜂鸣器来使其发声
按键判定
```cpp
bool isButtonPressed() {
  return digitalRead(BUTTON_PIN) == LOW;
}
```


## 遇到的问题 & 怎么解决的

> 现象：蜂鸣器发出咔哒声  
> 我猜的原因：蜂鸣器没有连接好，代码错误  
>试了什么:重新组装，修改代码  
>真正的原因:无源蜂鸣器被直流驱动  
>现象：设备管理器报错误码 28，无串口   
>我猜的原因：设备没有安装好  
>试了什么：重新组装，重写代码  
>真正的原因：驱动不对，需要FTDI驱动

## 我理解的关键概念

loop()函数是显性调用，可以使亮度与按键彻底分离  
tone() / noTone()	启动/停止方波输出；  
VID/PID：VID指的是厂商编号，PID指的是产品编号：系统通过VID/PID去寻找对应的驱动

## 最佳实践

1. **先确认引脚能力**：D13 无硬件 PWM，必须软件 PWM；要更平滑就外接 LED 到 D9。
2. **按钮一律用内部上拉**：一端接引脚、一端接 GND，省去外部电阻且不易出错。
3. **先判断蜂鸣器类型再写驱动**：用「直流高电平 vs 方波」两段测试，一步区分有源与无源。
4. **状态切换才调用 tone()**：重复调用会导致声音抖动，用状态变量控制。
5. **显式轮询、天然消抖**：在 `loop()` 每个亮度步（10 ms）显式调用 `updateBuzzer()`，既省事又天然消抖，调用关系也一目了然。
6. **上传后按一次 RESET**：FTDI 板常见行为，避免「程序没跑」的误判。
7. **用回读校验确认固件**：`avrdude -U flash:r` 后与编译产物比对，差异为 0 才说明写入正确。
8. **参数集中管理**：引脚、频率、步长都放文件顶部宏定义，调整时不碰逻辑代码。

## 总结  

本项目是一个运行在 Arduino UNO R3 上的 LED 呼吸灯与按钮联动蜂鸣器程序：通过软件 PWM 驱动 D13 板载 LED，让亮度在 关-亮-关 之间平滑往复变化，形成约 2.56 秒一轮、无跳变的自然呼吸效果；同时 D2 引脚接有一个按钮，按下时 D8 上的无源蜂鸣器鸣响，松开即停止，LED 呼吸过程不受影响。整个项目只使用 Arduino 官方框架，无需任何第三方库，代码结构清晰、参数集中在文件顶部便于调整，可直接编译烧录后稳定运行。
